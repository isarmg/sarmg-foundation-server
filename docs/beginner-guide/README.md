# 开发者导读

第一次使用 xcss，先完成[开始接入](../getting-started.md)中的最小示例。修改本仓代码时，按[构建与测试](../development.md)准备工具链。

随后按任务选择阅读路线：

- Rust 服务端：[模块](../reference/modules.md) → [认证](../reference/authentication.md) → [运行时](../platform-specifications/server-runtime.md)
- 管理 Web：[组合页面](../usage.md#管理-web) → [HTTP 客户端](../reference/http-client.md) → [内嵌构建](../reference/embedded-web.md)
- 数据与文件：[合同与 SQLite](../reference/contracts-and-schema.md) → [文件句柄](../filesystem-handles.md) → [状态与日志](../configuration-cli-logging.md)
- 发布维护：[构建检查](../development.md) → [发行工具](../operations.md) → [产品验收](../development.md#验证实际消费者)

这些路线可以独立阅读。完整专题见[参考索引](../reference/README.md)。
