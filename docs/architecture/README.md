# Architecture Decision Records

中用例外或兼容分支绕过。

| [0003](ADR-0003-single-platform-implementation.md) | 产品不实现第二套平台能力 |
| [0004](ADR-0004-current-only-offline-upgrades.md) | current-only 与离线升级所有权 |
