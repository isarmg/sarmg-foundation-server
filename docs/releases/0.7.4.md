# Foundation Server 0.7.4

本版本优化管理 Web 的冷启动字体路径。`@sarmg/web-fonts` 新增 Regular/Bold 两个 `Sarmg Maple Bootstrap` WOFF2，合并完整拉丁字符和五个服务端管理 Web 的 512 个静态 UI 字符；完整 Maple CJK 分片仍作为低频字符回退，字体源覆盖范围不变。

管理外壳只等待两个首屏字体，不再等待 `document.fonts.ready`。等待上限为 1.2 秒：字体成功时整页直接使用 Maple；超时或失败时，本次导航固定使用系统等宽字体，避免晚到字体引起二次切换。

首屏字体由固定字表和已验证的 0.7.3 字体产物可复现生成，每个文件小于 256 KiB。更新没有修改 `maple-font` 仓库源码。
