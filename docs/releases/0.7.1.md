# Foundation Server 0.7.1

文件服务 Profile 现在可选择 `web-embedded-native` 或 `web-react-admin`。采用 React 的文件服务直接消费现有 React Shell/UI、固定版本的 React 工具链和默认内容块样式，不需要产品专用 Profile 或平台源码副本。

本次不改变认证、HTTP 连接、生命周期、文件安全及任务语义，也不启用新传输协议。新增合同测试覆盖两种合法 Web 选择及非法 Profile 的拒绝。Rust 与 Web 实现保持 0.7.0 的行为；版本、包清单、锁文件及发布身份统一为 0.7.1。

0.7.0 的 tag、提交和已发布制品保持不变。消费者应固定本次正式版本与完整 revision，不能仅使用可变分支。
