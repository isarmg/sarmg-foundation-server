# Sarmg Foundation Server 0.7.7

Static administrator sessions are now physically removed when expired, revoked, or displaced by capacity limits. Active-session metrics use the same expiry rules as authentication, and the process-local audit buffer retains only the newest 4096 events.

Administrator Web authentication isolates subscriber failures. A failed logout remains locally signed out and renders an explicit unconfirmed-server-session warning on the sign-in screen; the account-update notice is consumed after the next successful login.

XML budgets now run through a streaming preflight before the borrowed document tree is built, avoiding the previous full-tree work before node, depth, text, declaration, and time checks. Public HTTPS also rejects non-public destination ranges and disables proxy bypasses of pinned DNS addresses.

The first-paint Maple faces contain only the reviewed UI glyph set, and application startup waits only for the regular face. Web CI builds once before typechecking, tests, and browser acceptance. Listener binding semantics for mixed fixed and zero ports are now explicit and covered.
