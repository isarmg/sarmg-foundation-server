# Sarmg Foundation Server 0.6.0

原 Foundation 仓库保留 Git 历史并改名为 `sarmg-foundation-server`，只规定 Server 及其管理 Web。Agent、移动 FFI 和客户端本地管理 Web 独立到 `sarmg-foundation-agent`；两个基础仓库不互相依赖。

- 21 个服务端 Rust crate、8 个 Web 包和服务端 Profile，采用统一的 0.6.0 版本。
- 管理员管理、HTTP 请求体限制、共享管理界面、诊断、设计令牌及原生 Web 构建支持。
- 文件句柄安全操作、SQLite 管理数据、持久化操作和服务端运行时基础能力。
- 不可变 Git revision、npm 发行 tarball 和校验清单；保留旧标签历史，但不提供旧名称或旧合同兼容入口。

本版本是当前改造工作的阶段发布，不表示《更新手册》全部完成。消费者矩阵记录其具体提交的采用情况，不将本地工作区集成等同于已发布产品验收。仍需按产品完成剩余能力接入和原生平台、外部服务端到端验收。
