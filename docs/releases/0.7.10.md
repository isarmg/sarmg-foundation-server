# Sarmg Foundation Server 0.7.10

- Conformance 不再维护消费者产品名称清单，也不再以产品名决定 DDL、Feature 或依赖方向。
- Cargo 依赖检查解析 `package` alias，并从 Foundation 自身工作区推导真实包边界。
- 路由和安全常量文本扫描降级为迁移建议；Schema 所有权由 SQLite Composer 的实际重组结果判定。
- Schema 与 Web 根目录支持唯一发现或 `sarmg-layout.toml` 显式声明，不再绑定固定仓库布局。
- `verify-schema` 逐字比较重新组合的当前 Schema，不能再由生成注释伪造通过。
- 消费者报告测试改用合成仓库，不再把某个真实消费者的版本或迁移状态写入 Foundation 核心测试。
