# Sarmg Foundation Server 0.7.0

受限 Axum HTTP/1 启动入口和有限生命周期更新。这是当前合同的破坏性变更，不保留 0.6.x `serve(listener, router)` 包装入口。

- `HttpServer`、`BoundListeners` 和 `ProcessSignals` 明确表达先安装信号、全部绑定、再构造产品状态的顺序。
- 多监听地址共享接受前配额；请求头期限、缓冲、socket 写入空闲期限和可中断退避由平台统一执行。
- Request ID 在 Router 外只安装一次；平台 Router 不覆盖产品的流式 Body 预算。
- `WorkScope`、`TrackedTasks` 和 `LifecycleParticipant` 分离普通任务、不可随意取消的提交及最终状态关闭。硬期限返回未完成工作报告，不将 abort 当成可靠停机。
- `server-filesystem` 只使用 Axum，保留静态管理员、内存 Session 和原生内嵌 Web；文件系统安全、上传恢复、文件操作状态机仍属于产品。

迁移必须同步更改消费者的启动调用、完整 Foundation revision 与当前版本身份。旧数据库不会因此获得隐式兼容能力。Dufs 的产品验收和发布结果单独记录，不以平台测试代替文件安全验收。
