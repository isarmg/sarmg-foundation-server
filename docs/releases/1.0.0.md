# xcss 1.0.0

此版本将当前实现整理为 1.0.0 发布基线，正式标签为 `v1.0.0`，`main` 从一个初始提交开始。

项目、软件包、命令、服务及安装产物按统一四字母命名表更新；最后一位 `s` 表示服务端。当前项目名为 `xcss`。服务端基础支撑物理合并为单体：服务端只使用 Rust crate `xcss` 与单个 `@xcss/web` npm 包。xcss 整个 crate 与 Node 构建进程仅支持 Linux AMD64 GNU。

产品依赖固定到新的 1.0.0 基础库和提交。协议版本、数据库结构版本及第三方工具版本独立管理，不随软件发布版本重置。

产品通过更新固定 Rust/npm 依赖、重建和测试接入本版。安装与状态处理按产品实际发布说明执行。

参见[项目 README](../../README.md)。

## 内部版本从初始值开始

本次重建的软件发行号为 `1.0.0`。项目自定义的配置、持久状态、数据库 schema、API、通信协议、ABI 和发行清单均以 `v1` 或数值 `1` 作为初始标识；使用语义版本作为身份的配置采用 `1.0.0`。第三方依赖、外部软件 API 和字体上游版本遵循其实际版本要求。

公共库更新与产品协议、持久状态身份分别核验；本库没有独立安装或配对流程。

## 单体发布结构

Rust 内部能力经 `xcss::<module>` 导出；Web 经 `@xcss/web/<module>` 子路径导出。各子目录不含独立 Cargo/npm 清单，模块没有独立版本或发布包。Web 唯一制品为 `xcss-web-1.0.0.tgz`；消费者只安装它并固定真实 SHA-512 完整性摘要。浏览器仍可跨平台访问已部署的服务端管理页面。
