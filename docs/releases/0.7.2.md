# Foundation Server 0.7.2

管理 Shell 右上角新增圆形人物图标，可修改当前账号名称和密码。新增受会话、同源及 CSRF 保护的 POST /api/v2/platform/administrators/self 接口，验证当前密码后原子更新账号并撤销全部会话；账号 ID 保持不变。

SQLite 无需修改数据库格式。静态账号可显式启用受保护目录中的原子文件持久化，重启后保留账号修改；原有纯静态模式保持只读。React 组件也可供自定义文件服务页面复用。

验证覆盖 Axum/Hyper HTTP 合同、SQLite 事务及并发失效、静态账号重启和符号链接拒绝、Web 认证请求竞态、Chromium/Firefox 账号交互与 WCAG AA。消费者需固定 0.7.2 的完整 Git revision 和 npm tarball integrity。
