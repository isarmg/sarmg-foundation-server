# Foundation Server 0.7.5

0.7.5 是本轮字体启动优化的正式消费基线。它继承 0.7.4 的首屏 Maple 子集、1.2 秒有界字体门控和稳定系统字体回退，并将所有 npm、Rust 与消费者矩阵版本统一到 0.7.5。

首屏只预取常规与粗体两份启动字体，总计约 328 KiB；完整 CJK 分片继续作为稀有字符的按需回退。生成过程只读取既有字体发行产物，没有修改 `maple-font` 仓库源码。

## 验收

- npm 工作区测试与发行包校验通过。
- Rust 工作区测试与打包校验通过。
- 启动字体可复现构建、许可来源和 SHA-256 provenance 校验通过。
- 下游服务固定使用本版本对应的 Git 提交，不依赖浮动分支。
