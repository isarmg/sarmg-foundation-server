# Foundation Server 0.7.6

0.7.6 为所有 Server 管理 Web 提供统一的内容垂直间距。Foundation 新增 `--sarmg-content-spacing` 语义令牌，默认值为 16px，并提供 `sarmg-content-stack` 内容栈；菜单栏到首行内容、相邻内容区块以及正文到子标题均使用同一默认距离。

内容栈会归零直接子项原有的块级外边距，再由统一 `gap` 控制间距，避免标题浏览器默认外边距、表格包装器和产品局部样式叠加成不同距离。原生工作区和实例详情也使用同一令牌，产品仍可在自身作用域覆盖该值。

## 验收

- Chromium 与 Firefox 在桌面及移动宽度下验证菜单到首行内容和正文到子标题均为 16px。
- npm 工作区类型检查、单元测试、浏览器测试与发行包校验通过。
- Rust 工作区质量门与不可变发行身份校验通过。
- 消费者快照由 Foundation 同步脚本生成，未修改 `maple-font` 源代码。
