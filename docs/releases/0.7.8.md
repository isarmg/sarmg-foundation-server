# Sarmg Foundation Server 0.7.8

This patch republishes the current Server Foundation runtime and administrator UI baseline under a new immutable version. Session and audit bounds, streaming XML preflight, logout-state isolation, public HTTPS admission, font bootstrap, and listener semantics are unchanged from 0.7.7.

All Rust crates and Web packages are versioned together at 0.7.8 and rebuilt from the tagged source with release identity and inventory checks.
