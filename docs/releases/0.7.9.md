# Sarmg Foundation Server 0.7.9

Foundation build and release verification now proves only the public platform implementation and its own packages. The consumer matrix remains available as an independently maintained adoption report, but a fixed downstream product list or stale product baseline can no longer block Foundation CI or Release.

Administrator workspaces now share the same instance-list, detail, configuration, and log navigation model. Projects can expose overview and instance summaries without rebuilding their own layout behavior.

Language changes take effect immediately without a confirmation dialog. The shared shell and language contract tests now enforce this behavior across consuming Server projects.
