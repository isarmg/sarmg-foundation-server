# xcss 1.0.1

本次补丁版本统一 Rust crate `xcss`、Web 包 `@xcss/web` 和随发行提供的工具身份为 `1.0.1`。正式标签为 `v1.0.1`，Web 制品为 `xcss-web-1.0.1.tgz`。

## 相对 1.0.0 的变更

- 修复受控输入框与选择框保留过期原生校验错误的问题：加载已有记录或更新受控值后重新计算有效性，同时保留调用方的自定义校验。加入空白实例名称和原生表单提交的浏览器回归测试。
- 字体启动检查改为显式选择公共字体目录或消费者提供的页面 URL，支持亮色、暗色及可选的 storage-state；移除对特定产品页面与路由的耦合，并加入参数和静态资源处理测试。
- 整理接入、配置、开发、使用、排查与参考文档；为一般文档变更选择较轻的 CI 路径，发行和构建输入仍执行完整验证。
- Web 根导出的版本从 `package.json` 生成，避免发行版本更新后构建元数据仍保留旧值。

前三项依据 `v1.0.0` 至 `3e38bb3942774f717105edccb1981e27e0f84338` 的已提交变更；版本身份与构建元数据同步在本次发行准备中完成。

## 接入与边界

消费者应同时更新精确 Rust 版本和完整 Git revision、正式 Web tgz URL 及真实 SHA-512 完整性摘要，重新构建并运行产品测试。不能用旧 `1.0.0` 归档表示本次修复，也不覆盖旧标签或资产。

仍仅支持 Linux AMD64 GNU 的 Rust 与 Node 构建输入。协议、持久状态、数据库 schema 和发行清单格式保持原有身份；软件发行版本更新不改变这些格式与约定。

发行工作流在精确标签和干净源码上生成资产。发布后按[发行工具操作](../operations.md)回下载验证完整性、发行身份和消费者构建结果。
