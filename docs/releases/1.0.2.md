# xcss 1.0.2

本补丁将 Rust crate `xcss`、Web 包 `@xcss/web` 和随发行提供的工具版本统一为 `1.0.2`。

## 修复

- 修复共享 `Dialog` 的 Tab 循环拦截原生视频控件的问题，使仅有关闭按钮与视频控件的播放窗口可通过键盘进入视频控件。
- 含原生媒体控件的对话框采用浏览器原生焦点移动；普通表单对话框的 Tab 循环、Escape/关闭和焦点恢复行为保持不变。

## 验证与接入

浏览器回归覆盖视频控件及视频 + PTZ 按钮场景。Chromium 与 Firefox 合计 68 项用例通过，见[修复候选 CI](https://github.com/isarmg/xcss/actions/runs/38076480238)。

消费者应固定 Rust 版本 `=1.0.2`、该发行的完整 Git revision、Web tgz URL 和真实完整性摘要，再构建与测试产品。接入步骤见[README](../../README.md)和[开始接入](../getting-started.md)。
