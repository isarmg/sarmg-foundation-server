# Sarmg Foundation Server 0.8.0

0.8.0 删除 Foundation 的实例侧栏抽象，所有管理页面默认使用全宽内容。实例选择统一在产品实例列表中完成，顶部“实例列表 / 详细信息 / 日志”导航保持不变。

- 删除 React `InstanceWorkspace` 公共导出及相关参数。
- 删除 `WorkspaceConfig.layout` 与 `emptyInstanceSidebar`，保留顶部导航使用的 `selection`。
- 精简原生 `configureNativeWorkspace`，删除仅服务于侧栏的内容、实例名称、实例链接和实例区标签参数。
- 删除 `.sarmg-instance-*` 与 `.sarmg-native-workspace` 外观规则。
- 保留实例名称校验、顶部新建/刷新、语言、主题、退出和账户操作。

这是公共 API 删除，消费者必须先移除旧组件、配置与 CSS 类，再升级到 0.8.0。
