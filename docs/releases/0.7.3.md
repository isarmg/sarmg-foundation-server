# Foundation Server 0.7.3

本版本修复管理 Web 首次加载时的会话恢复文字闪现：会话恢复和核心字体准备完成前使用不透明的启动表面，完成后再显示登录页或已认证工作区。

核心 Maple 字体改为阻塞式加载，并由 Web 外壳等待核心字体就绪，避免先显示默认字体再切换到 Maple。字体生成脚本、快照校验和字体来源摘要同步更新。

管理 Web 不再显示独立的“管理员账号”列表或平台管理员页面。管理员名称和密码仍可通过右上角人物图标修改；认证、Session、CSRF 和自助修改接口保持不变。

消费者需固定本版本的完整 Git revision，并重新同步 Foundation 外壳、字体和 npm 包。旧的 `v0.7.2` 标签及其 Release 资产保持不可变。
