# Foundation 0.8.2

- 管理员 Web 接口收敛为单管理员自助账户更新；旧列表、创建、指定 ID 改密和停用接口及其公开类型已删除。
- Session CSRF 改为基于会话秘密和固定用途标识的稳定 HMAC-SHA256 派生值。升级后旧会话需要重新登录。
- Web 认证操作使用同一队列；退出失败保留内存撤销上下文并提供明确的重试操作。
- 管理员启动校验恢复为只读；非法单管理员状态会阻止启动，不再自动停用账户或撤销会话。
- 修复安全 HTTP 的 IP 字面量绑定、完整操作期限和 `100::/64` 判断，以及 XML 引用与相邻文本预算。
- SQLite 先读后写入口预先取得写事务；Durable Operation 完成接口按完整领取快照校验 owner、attempt 和 expiry。
- Release 增加 Foundation conformance 与 Chromium/Firefox 门禁；npm smoke 按正常 peer 规则消费真实 tgz，并执行 TypeScript 与 Vite 构建。
- 统一默认 Maple Bootstrap 字体优先级，正文和等宽文本在成功或回退时使用同一字体选择。

这是包含公开接口删除和签名调整的新版本。不得覆盖 `v0.8.1` 标签或资产。
