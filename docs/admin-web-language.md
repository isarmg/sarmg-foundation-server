# 管理 Web 语言约定

管理 Web 支持简体中文（`zh-CN`）和英文（`en`）。语言选择优先级为明确的 `?lang=` 参数、本站保存的语言偏好、浏览器语言。中文浏览器使用简体中文，其他语言回退英文；不使用中英混合回退。

- 登录页和顶部工具栏提供语言图标。切换前显示可取消的确认对话框，确认后重新载入当前路径和页面。未保存的编辑不跨语言恢复，密码、配对码和其他表单内容不写入存储。正在提交的表单阻止切换。
- 唯一持久化值是 `localStorage["sarmg.admin.language"]`。存储不可用时，当前 URL 的语言参数仍可工作。设置 `document.documentElement.lang`，日期按所选语言格式化。
- 每个已载入的页面固定使用一个语言。其他标签页修改偏好不会让本页局部变更语言；偏好只在新页面成功载入后保存，取消浏览器的离开页面提示不会提前提交偏好。
- `@sarmg/admin-ui/i18n` 的 `t(中文, English, 参数数组)` 提供显式成对文案和编号插值。正文、按钮、通知、表单校验、空状态、错误、确认弹窗以及无障碍标签都必须有两种语言。不得扫描或翻译任意 DOM、用户数据、响应内容。
- 产品品牌、协议名称、可执行文件名、设备标识、路径和用户命名保持原样。业务状态枚举、配置选项和字段名称在产品中映射为显示文案，不能翻译请求值、数据库字段或状态机分支。
- 不直接把服务端自然语言消息当作已本地化 UI。产品依据稳定的事件类型和错误码生成本地文案；未识别的状态如实显示“未识别”，不猜测结果或触发重试。
- `sync-admin-shell.mjs` 同步共享 Shell、UI 和语言模块的可校验源码快照，不修改已发布的不可变 npm 包。React 消费者将 `@sarmg/admin-ui` 的精确入口指向 `shell/ui.js`，CSS 入口保持原样；原生消费者通过自己的构建入口导出语言模块。

验收包括两种语言下的登录、切换与取消、偏好保存、存储受限回退、插值不解释 HTML、表单内容不持久化、业务操作协议值不变，以及 Chromium/Firefox 的键盘、无障碍和移动布局检查。`scripts/check-web-language.mjs` 可用于产品自有 API 测试夹具；仅可豁免夹具中的用户名称，不可豁免界面文案。
